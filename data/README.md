# 数据说明

这里仅管理可公开的数据说明与变量字典，不存放患者级数据。

- 原始数据：机构批准的受控位置；不得上传。
- 本地目录 raw/、processed/、private/、local/ 已被忽略。
- CSV、Excel、PDF等并未按扩展名全部屏蔽，以便维护字典及公开汇总材料；提交前仍需逐项检查内容。
- 授权访问：待项目负责人补充申请流程，不公开访问凭据或敏感路径。
- 数据版本、采集时间、纳排标准、清理规则与冻结日期：待填写。

使用 data-dictionary.csv 记录实际变量，补充类型、单位、取值、缺失值规则及派生公式；不要将真实病例作为示例。当前字典只有表头。
